# Course project for COSC 202 Data Science and AI
The project consists of training an ANN using the existing dataset included in the diabetes.csv file
---
The machine learning proccess was done using Keras, a machine learning module included in the tensorflow python library  
The dataset was cleaned and made ready using Pandas and NumPy  
---
## How to run
- Run the jupyter notebook **Training_Project.ipynb**
- A trained model will be saved in the current directory as **saved_model.keras**
- Run the jupyter notebook **Testing_Unseen.ipynb**, which will use the save model on the **Unseen_Data.csv** dataset
